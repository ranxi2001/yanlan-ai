配置 MiMo 语音转写

官方接口地址、协议和转写路径已由言澜处理。

1

获取按量 API Key

在 Xiaomi MiMo 开放平台创建 sk- 开头的 Key。默认 Base URL 无需修改。

2

粘贴并保存

将 Key 填入“MiMo API Key”，保存后即可录音或上传音频。模型、协议和接口路径均已预设。

3

遇到网络错误

先确认 Key 和额度；若服务不允许浏览器跨域，请在本机运行言澜并选择“本地同源网关”。

不要混用两类 Key：sk- 是按量 API Key；tp- 是 Token Plan 专属 Key。Token Plan 当前面向 AI 编程工具，会议转写应使用按量 API Key。
