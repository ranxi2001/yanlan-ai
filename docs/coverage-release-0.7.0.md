# 0.7.0 音频覆盖检查接入

2026-09-10。默认启用“检查转写遗漏”。上传、重转和恢复采用最长 30 秒的流式窗口。直接连接模型时，浏览器用 20 毫秒帧的 RMS 活动量与文字密度提示疑似漏转；它不是 VAD，也不能区分背景噪声和人声，不会自行补写内容。

## 本地双模型模式

```powershell
npm run setup:coverage
npm run local
```

安装命令创建仓库内独立 `.venv-coverage`，安装 `server/coverage-requirements.txt` 中的 CPU 依赖，并在缺少模型时下载 SenseVoice Small int8 的 ONNX 与 tokens。已有 `artifacts/models/sensevoice/` 会直接复用。模型为上游 SenseVoice 的 Apache-2.0 许可转换版本，见 [SenseVoice](https://github.com/FunAudioLLM/SenseVoice) 和 [ONNX 分发](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17)。模型没有打入网页或 npm 包。

在本机页面设置中选择“本地同源网关”，保留“检查转写遗漏”勾选，再上传或重新转写。可以用 `YANLAN_COVERAGE_PYTHON` 指定已有 Python，`YANLAN_SENSEVOICE_DIR` 指定包含 `model.int8.onnx` 和 `tokens.txt` 的目录。模型按需加载为持久化 CPU 子进程；服务关闭时退出。网关始终监听本机地址。

完整文件每个通过初始质量门的短窗口由本地 SenseVoice 扫描；只有存在缺失/分歧且预算允许时，才向已配置的 MiMo 发送同一批短片。两路使用完全相同的 PCM16，逐片校验 SHA-256。不向本地进程提供密钥、参考稿或主 ASR 文本，不记录音频和逐字稿日志。

结束录音后，已完成的实时结果会从本地录音补做覆盖扫描，不重新请求整场主 ASR。实时转写失败的录音仍走完整重转恢复路径。不同时间归属、多片段或提供方说话人标签存在时，不自动把新增内容归给现有说话人。

## 接纳、持久化与失败

接纳继续使用 `supplementAsrCoverageTail`：局部唯一锚点与两路一致词面；敏感替换、删除、分歧和歧义保留待复核。新增尾部可以包含两路一致识别的新事实，因此仍需人工检查重要内容。

`rawSegments[].text` 保留初始 ASR；仅在接受补丁时，在该片段的 `asr_coverage` 中保存源文字/时间/说话人绑定、原窗口、本地短片与远端短片的文字和音频哈希。`reconcileTranscriptSegments` 与 `replayTranscriptReconciliations` 首先重新推导覆盖修正，再处理已有边界与术语台账。正式 `segments` 不携带复核 payload，分享和导出使用正式正文，不包含私有台账。

服务失败、超时、预算不足或证据不完整不会清空已有逐字稿；UI 显示降级或待回听提示。取消会阻止提交。复核请求最多排队 4 项，单次 120 秒；进程失败清理待处理任务。接口校验本机 Host、同源 Origin、方法、PCM 大小与连续分片帧数。

## 预算和适用范围

额外 MiMo 音频最多为已知录音时长的 15%，额外请求最多为预计基础窗口数的 30%，复核请求不自动重试。未知时长按累计完成的窗口获得预算，较早没有预算的疑难片段标记待回听；短录音可能没有足够预算做完整复核。按在线到达顺序预约预算，不缓存整场 PCM，不进行离线全局风险排序。本地推理和录音结束后的再次解码不包含在这两个远端预算中，尚无端到端耗时上限承诺。

浏览器活动量、固定 30 秒主窗与固定短窗，是部署条件下的新组合，与离线 Silero VAD 实验不同。此前开发集 CER 13.96% → 12.62% 只属于已有实验，不能套用为本版本的生产准确率。静态网页版没有 SenseVoice，不会声称完成双模型复核；整文件兼容模式明确标记未执行覆盖检查。

## 本轮验证

- 全仓库测试 318 项通过、1 项跳过；生产构建与 0.7.0 npm 安装/CLI 运行验证通过。
- 新增浏览器回归实际上传 210 秒合成 WAV：7 次主窗转写、本地扫描 7 个窗口、额外 MiMo 请求 2 次；1 个窗口补回、6 个窗口因预算留待回听。模型为受控测试响应，该用例验证产品行为，不计为语音精度成绩。
- 浏览器验证覆盖旧配置默认启用、精确 PCM 哈希、原文保留、GPT 失败后的回退、刷新恢复、设置关闭及桌面/移动布局。现有完整录音恢复、重试、删除竞态、分享测试通过。
- 真实本地 SenseVoice 成功识别公开 AISHELL-1 样本。另对已知 25.456 秒漏转案例，复用历史真实主 ASR 输出，新执行本地识别及 2 次 MiMo 补听：成功触发缺失与分歧提示，但本次证据不满足补回条件，原稿 78 个字符保持不变。没有将模拟成功用例当作真实自动补回收益。
- 官方 npm registry 审计发现的 nanoid 高危依赖问题已更新至 3.3.18；修复后审计为 0 漏洞。
